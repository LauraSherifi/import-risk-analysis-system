Note on missing-value flags:
Missing-value flag columns were considered during the cleaning process, 
but they were not kept in the final cleaned dataset.

The reason is that the percentage of missing values was very low compared 
to the total number of records. For example, the dataset contains 263,821 rows, 
while only 13 values were missing in weight, 184 in length, 2,638 in shipment date, 
and 26 in destination port.

Because most rows would have a value of 0 in the flag columns, keeping these 
additional columns would make the dataset larger and more complex without adding 
much value at this stage of the project. Instead, the missing values are documented 
in this report.


Cleaning method summary:
The dataset was cleaned by standardizing column names, converting data types, 
checking for duplicate rows, and handling missing values. The column names 
were renamed to make them easier to use in Python and machine learning 
workflows. The shipment_date column was converted from text/object format 
into datetime format.

Missing numeric values in weight_kg and length_m were filled using the 
median value for the same product_name where possible. If a product-level 
median was not available, the overall median value was used. 
Missing shipment_date values were filled using the median shipment date 
from the dataset. Missing destination_port values were filled with the category "Unknown".


Final summary:
The data preparation step was completed successfully. 
The cleaned dataset contains the same number of rows as the original dataset, 
has no remaining missing values, has no duplicate rows, and uses clean column 
names and correct data types for the next machine learning steps.
